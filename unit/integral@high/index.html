定积分的直观意义

所属概念：积分 · 曲边梯形 / 面积

1 从「求面积」开始

小学学长方形面积 = 长 × 宽。初中会算三角形、圆的面积。 但曲线下方的面积怎么算？没有一条公式能套。

定积分就是解决这个问题的：用无穷多个细长矩形去逼近。

2 逼近的过程

把 [a, b] 切成 n 段，每段宽 Δx，高度取该段上函数值：

S ≈ f(x₁)Δx + f(x₂)Δx + ... + f(xₙ)Δx

n 越大，误差越小。当 n → ∞（且 Δx → 0），这个和的极限就是曲边梯形的面积：

∫ᵃᵇ f(x) dx = lim  Σ f(xᵢ)Δx

符号 ∫ 是一个拉长的 S（Sum），dx 提醒你这是「宽度趋于 0 的细条」。

3 一个反直觉的性质：有向面积

定积分算的不是「面积」，是有向面积：x 轴上方的部分记正，下方记负。

∫₀² x dx = 2        （正）
∫₋₁¹ x dx = 0       （左右抵消）

这解释了为什么奇函数在对称区间上的积分总是 0——正负面积完全相等。

如果只把积分当面积，这个性质会显得像 bug；把它当「累积量」，它就是合理的。 物理上，速度积分得到位移（可正可负），而不是路程。

4 与导数的关系：微积分基本定理

牛顿-莱布尼茨公式：

∫ᵃᵇ f(x) dx = F(b) − F(a)     其中 F' = f

它是说：累积的变化率就是原函数本身。

一个直观的读法：如果 F(x) 表示「从 a 到 x 累积了多少」，那么再往前挪一点点 dx， 新增的累积量正好是 f(x)·dx。所以 F'(x) = f(x)。

这个定理把「求面积」这件难事，变成了「找一个原函数」这件相对简单的事。

5 螺旋：高中只要求「算」，大学要求「为什么能算」

导数（高中）知道 f' 是什么
   ↓ 反过来问：谁能求导得到 f？
定积分（高中，直观）用原函数算面积        ← 本页
   ↓ 严格化：黎曼和、可积性
定积分（大学）哪些函数可积？为什么？

高中的关键限制：只处理连续函数。大学要面对有间断点的函数， 要区分「黎曼可积」与「不可积」，还要证明基本定理成立的条件。

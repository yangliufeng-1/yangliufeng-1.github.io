向量代数与空间解析几何

所属概念：向量 · 叉积 / 平面方程

1 从「箭头」到「抽象元素」

高中向量的定义是几何的：有大小和方向的量。你会画它、平移它、算它的长度与夹角。

大学的第一步是把这个定义丢掉，换成公理化的：

向量是满足八条运算律的元素。长度和方向不再是定义的一部分， 而是内积这层额外结构给出来的。

这不是为了抽象而抽象。一旦这样定义，很多不是箭头的东西也能叫向量： 多项式、矩阵、连续函数，甚至量子态。它们都能做同样的加法和数乘。

2 线性相关：整个学科的核心概念

一组向量 {v₁, v₂, ..., vₙ} 线性相关，如果存在不全为 0 的系数使：

c₁v₁ + c₂v₂ + ... + cₙvₙ = 0

直观翻译：其中至少有一个向量是其余向量的「组合产物」，它没有提供新方向。

高中已经在用这个概念，只是没给它名字：

高中说法 大学的说法
两个向量共线 两个向量线性相关
三个向量共面 三个向量线性相关
(3,4) 与 (6,8) 平行 {(3,4), (6,8)} 线性相关

「共线」「共面」只能描述 2 维和 3 维，线性相关能描述任意维。 这正是抽象的价值：把低维直观的结论，推广到看不见的维度。

3 叉积：只有 3 维才有的运算

a × b = |a||b|sinθ · n

n 是垂直于 a、b 所在平面的单位向量（方向由右手定则定）。

叉积的三个用途，都是高中立体几何的痛点：

需求 叉积的做法
求平面法向量 平面上两个不共线向量叉积即得
判断共面 三向量混合积为 0 ⟺ 共面
平行六面体体积 混合积的绝对值

高中求二面角要作辅助线、找垂足；大学用叉积得到法向量，再算两个法向量的夹角。 这是本项目里「同一问题被重新建模」最戏剧化的一处。

4 空间解析几何：把几何搬进坐标

对象 方程形式
平面 Ax + By + Cz + D = 0，法向量 (A, B, C)
直线 对称式 (x−x₀)/l = (y−y₀)/m = (z−z₀)/n
球面 (x−a)² + (y−b)² + (z−c)² = R²

有了方程，几何问题变成解方程组： 「求两平面交线」= 解两个方程组的公共解；「判断线面位置关系」= 比较方向向量与法向量。

5 螺旋的最后一环

共线 / 共面（初中、高中，只能画 2、3 维）
   ↓ 抽象掉维度
线性相关（大学）维度无关的判断             ← 本页
   ↓
线性代数：基、维数、线性变换

注意这条链上「螺旋」的含义最纯粹： 同一个判据（是否存在非平凡线性组合为零），从 2 维图示变成了任意维的代数条件。

6 对应教材

同济版《高等数学》下册第八章。教材从向量代数讲到平面方程、直线方程、曲面方程， 再统一到空间曲线。平面与直线的处理放在叉积之后，因为没有法向量的工具， 后面所有方程都失去来源。

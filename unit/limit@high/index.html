极限的直观理解

所属概念：极限 · 无限趋近 / 极限存在

1 导数之前必须先有一个东西

高中教材用「割线趋近切线」讲导数，中间跳过了一步： 凭什么可以取极限？ 如果割线斜率忽左忽右、不趋于任何固定的数呢？

极限就是回答这个问题的工具。它不谈「到达」，只谈「越来越接近」。

极限的定义里从没有「等于」这个词。x → 2 说的是 x 无限接近 2，但不必等于 2。

2 一个必须自己想明白的例子

f(x) = x² − 4
       ───────
        x − 2

x = 2 时分子分母都是 0，函数在这里没有定义。但问「x 接近 2 时，f(x) 接近什么」是有意义的：

x f(x)
1.9 3.9
1.99 3.99
1.999 3.999
2.001 4.001
2.01 4.01

答案是 4。函数在 2 处没有定义，但极限存在。

这个区别是高中数学最容易被混掉的一处：f(2) 不存在，lim f(x) 却可以存在。

3 为什么它能解释「割线变切线」

切线斜率 = 割线斜率的极限：

k割 = [f(x₀+Δx) − f(x₀)] / Δx
k切 = lim  k割   （当 Δx → 0）

对 f(x) = x²：

[f(x₀+Δx) − f(x₀)] / Δx = (2x₀Δx + Δx²) / Δx = 2x₀ + Δx

当 Δx → 0，结果趋于 2x₀。这就是导数的全部来源——不是新公式，是这个极限。

4 极限不存在的两种情形（用来识别陷阱）

情形 例子 现象
左、右趋于不同的值 f(x) = x/|x| 在 0 处 左边 −1，右边 +1
无界 f(x) = 1/x² 在 0 附近 越靠近越大，不趋于任何实数

第一种情形尤其重要：分段函数在分段点处的导数是否存在，必须分别看左右极限。

5 螺旋：这个词会在大学被完全重写

割线斜率（初中，k 恒定）
   ↓ 让 Δx 变小
极限（高中，直观）              ← 本页
   ↓ ε-δ 语言
极限的严格定义（大学）
   ↓
连续、可导、可积的严格理论

高中只需要算得出、看得出；大学要求 ε-N / ε-δ 的严格定义。 同一个词，从「越来越接近」变成「任意小的邻域内」，这不是难度增加，是语言换了。

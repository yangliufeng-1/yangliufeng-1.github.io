平面向量

所属概念：向量 · 数量积 / 共线

1 向量解决了一个几何的老问题

初中证明「平行」「垂直」「三点共线」，靠的是做辅助线、找全等、凑相似。 这套方法有天赋门槛——辅助线怎么想出来的，教材从不解释。

向量把几何变成计算：平行 ⟺ 坐标成比例，垂直 ⟺ 数量积为零，共线 ⟺ 存在实数 λ。

这不是「另一种解法」，这是把证明问题转化为代数判定。 与它同源的还有坐标系（coordinate@middle）：两者都是「用数描述图形」的努力。

2 向量的两个成分：大小与方向

向量不是「带箭头的线段」，而是大小与方向的有序对。关键推论：

  • 向量可以平移。起点在哪不重要，只有大小和方向算数。
  • 所以「AB→ = CD→」不等于「线段 AB 与 CD 重合」，只说它们等长且同向。

这个「可以平移」的性质，是向量区别于点的本质。点的位置是它的身份，向量的位置不是。

3 数量积：把「夹角」变成乘法

a · b = |a||b|cosθ

它的结果是一个数，不是向量。所以数量积又叫「点积」「内积」。

三条最有用的推论：

条件 等价于
a ⊥ b a · b = 0
a ∥ b a · b = ±|a||b|
cosθ 的值 (a·b) / (|a||b|)

第三条是几何题的万能钥匙：求夹角，不用作图，算一个除法。

4 一个必须澄清的混淆

学生常把「数量积为 0」和「向量为 0」混掉。用坐标就能看清：

a = (1, 2),  b = (2, −1)
a · b = 1×2 + 2×(−1) = 0     但 a ≠ 0, b ≠ 0

两个非零向量的数量积可以是 0，这恰恰是「垂直」的代数表达。 零向量与任何向量的数量积是 0，但那是平凡情形，没有几何信息。

5 螺旋关系

坐标系（初中）用数对描述点
   ↓ 从「点」升级到「方向 + 长度」
平面向量（高中）几何问题的代数化            ← 本页
   ↓ 维度提升
空间向量（高中）立体几何的代数化
   ↓ 推广到 n 维与一般线性空间
向量代数（大学）线性相关性、基、维数

同一套运算，维度一路上升，语义一路抽象。 高中停在 2 维和 3 维，因为那是能画出图的极限；大学不再依赖图。

6 对应教材

人教版 A 版必修第二册 §6。教材先讲向量的线性运算（加法、数乘）， 再讲坐标表示，最后讲数量积。「先有几何定义、再给坐标表示」这个顺序很重要—— 反过来讲，向量就退化成「一对数」，学生再也看不出它的几何意义。

7 自测

  • a = (3, 4)，b = (1, −2)。求 a·b、|a|、a 与 b 的夹角余弦。
  • 已知 a = (2, k)，b = (3, 6)，若 a ∥ b，求 k；若 a ⊥ b，求 k。
  • 用向量证明：三角形两边中点连线平行于第三边且长度为其一半。
  • a · a 等于什么？它和 |a|² 的关系说明了什么？

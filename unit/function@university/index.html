多元函数

所属概念：函数 · 多元 / 定义域

1 高中的函数，只有一个自变量

y=f(x)y = f(x)y=f(x)。输入一个数，输出一个数。

大学第一学期，这个限制被立刻打破：$z = f(x,y)$。输入一对数，输出一个数。

最普通的例子是海拔：给定经纬度 (x,y)(x,y)(x,y)，就有对应的海拔 zzz。这座山不是一条曲线，而是一整片起伏的地面。

从曲线到曲面，这是微积分真正意义上的第一步跨越。它不是「多学了一个变量」那么简单：所有关于「逼近」的直觉，都要在二维里重算一遍。

2 定义域从一条线段变成一个区域

高中的定义域是数轴上的一段，比如 [−1,3][-1, 3][−1,3]。

二元函数的定义域是平面上的一个区域，比如 x2+y2≤4x^2+y^2 \le 4x2+y2≤4 是一个圆盘。

对象 输入 定义域长什么样
一元函数 y=f(x)y=f(x)y=f(x) 一个实数 数轴上的一段
二元函数 z=f(x,y)z=f(x,y)z=f(x,y) 一个有序数对 平面上的一块区域
三元函数 w=f(x,y,z)w=f(x,y,z)w=f(x,y,z) 一个三元组 空间中的一块立体

定义域的写法没有本质变化，仍然是「让式子有意义的所有输入」。变化的是这个集合的形状：它不再是一段线段，而可能是一个圆盘、一个三角形，甚至是被一条曲线挖掉一块的平面。

例如 z=ln⁡(x+y)z = \ln(x+y)z=ln(x+y)，要求 x+y>0$——它就是直线 $x+y=0 上方的那半个平面。

3 「沿着一个方向可导，就能求导数」

这是从一元微积分带到多元微积分里最要命的一个直觉。

在一元函数里，「导数存在」和「可微」是同一件事。到了多元函数，两者分家了。

看这个经典例子：

f(x,y)={xyx2+y2,(x,y)≠(0,0)0,(x,y)=(0,0)f(x,y) = \begin{cases} \dfrac{xy}{x^2+y^2}, & (x,y) \ne (0,0) \\[4pt] 0, & (x,y) = (0,0) \end{cases}f(x,y)=⎩⎨⎧​x2+y2xy​,0,​(x,y)=(0,0)(x,y)=(0,0)​

在原点，沿 xxx 轴方向，$f(x,0) = 0$，偏导数为 0；沿 yyy 轴方向，同理为 0。

但如果沿着直线 y=xy = xy=x 逼近原点，$f(t,t) = \frac{t^2}{2t^2} = \frac{1}{2}$。

**沿着两条坐标轴都是 0，沿对角线却是 12\frac{1}{2}21​。**这个函数在原点甚至不连续，可它的两个偏导数都存在。

这说明：偏导数只看两个方向，而连续性要看所有方向。

在一元情形里，「左右极限都存在且相等」就够判断极限； 在二元情形里，「所有方向」是无穷多个，逐条检查是不现实的。 这正是多元微积分比一元难得多的根本原因。

5 教材里怎么放

人教版没有大学教材，高教版《高等数学》通常把多元函数放在下册第八章，紧接在一元积分之后。

顺序是：多元函数的基本概念 → 偏导数 → 全微分 → 复合函数求导 → 多元函数极值。

「偏导数」在「全微分」之前，这个顺序和小数、分数一样，是从局部到整体：先固定一个变量，看另一个变量怎么变，再把这些局部信息拼起来。

教材通常也会给出上面那个 xyx2+y2\frac{xy}{x^2+y^2}x2+y2xy​ 的反例，让学生看到「偏导存在不等于连续」。

本项目把「多元函数」单列为一个 Unit，而不是并入「函数」， 是因为它的难点不在定义，而在**「多少个方向」这个问题第一次出现**。

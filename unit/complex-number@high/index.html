复数的引入

所属概念：复数 · 虚数单位 / 共轭

1 一个被拒绝了两百年的数

x2+1=0x^2 + 1 = 0x2+1=0 没有实数解。这件事在初中就讲过了。

大多数人的反应是：没有就没有吧，题目就是这么出的。

但十六世纪的意大利数学家不这样想。他们在解三次方程时，中途必须对负数开平方——否则算不下去。于是有人硬着头皮写下了 −1\sqrt{-1}−1​，先算完，再看它会不会自己消失。

结果它没有消失。

2 定义只有一句话

i2=−1i^2 = -1i2=−1

就这一句。所有复数 a+bia + bia+bi 都是在这个基础上「算出来」的。

aaa 叫实部，$b$ 叫虚部。当 b=0b=0b=0 时，复数就是实数——实数是复数的一部分，就像整数是分数的一部分。

运算 规则 例
加减 实部归实部，虚部归虚部 (2+3i)+(1−i)=3+2i(2+3i)+(1-i) = 3+2i(2+3i)+(1−i)=3+2i
乘法 按多项式展开，再用 i2=−1i^2=-1i2=−1 (1+i)(1−i)=1−i2=2(1+i)(1-i) = 1-i^2 = 2(1+i)(1−i)=1−i2=2
共轭 虚部变号 2+3i‾=2−3i\overline{2+3i} = 2-3i2+3i​=2−3i

乘法这一步是关键：复数乘法不是「新发明的运算」，它和多项式乘法一模一样，只是最后要把 i2i^2i2 换成 −1-1−1。也正因为如此，复数加法满足「实部管实部、虚部管虚部」，两条线互不干扰，这让人很容易误以为复数就是两个实数拼起来的——后面会看到，它比这个更复杂。

3 「$i$ 是假的，复数不存在」

这是关于复数最普遍的态度，也很难反驳，因为「存在」本身就是个模糊的词。

但同样的质疑，历史上也发生在这几个数身上：

  • 负数：一度被视为「不可能的结果」，直到人们用它表示欠债和温度。
  • 无理数：毕达哥拉斯学派认为「$\sqrt{2}$」是亵渎，因为它无法写成两个整数之比。

**每一次数系的扩大，都是先「算出来」，再「找到意义」。**负数在账本里找到了意义，无理数在几何里找到了意义，复数则等了两个世纪，才在旋转里安顿下来。

复数的意义是在两个世纪后才被彻底看清的：它表示旋转。

乘以 iii，在平面上就是把一个点逆时针旋转 90°90°90°。乘以 iii 两次，就是转 180°$——也就是取相反数，所以 $i^2 = -1。

一旦这样看，$i$ 一点不神秘：它就是「转四分之一圈」这个动作的名字。

这也是高中引入复平面（把 a+bia+bia+bi 画成点 $(a,b)$）的原因： 只有画出来，学生才会发现，复数不是「假数」，而是「二维的数」。

依赖链：初中「乘方与开方」→ 高中「任意角与三角函数」→ 本单元「复数的引入」→ 大学「复变函数」。

5 教材里怎么放

人教版把复数放在高中数学必修第二册第七章，位置在平面向量之后。

先讲向量，再讲复数，这个顺序是有意的：复数和向量一样是二维的对象，都需要用平面上的点来表示乘积的旋转意义。

教材的顺序是：数系的扩充 → 复数的概念 → 复数的几何意义 → 复数的四则运算 → 三角形式。

教材开篇一定会讲「数系的扩充过程」：自然数 → 整数 → 有理数 → 实数 → 复数。每一步都是因为旧数系「不够用」了。

教材没有讲「复数不能比较大小」这条性质的证明，只给了结论。 但它值得记住：复数和实数最根本的区别，是它没有「大小」这个概念。

6 自测

  • 在复平面上，乘以 iii 相当于什么几何变换？验证 i2=−1i^2=-1i2=−1。
  • 为什么复数和实数不一样，不能说「3+4i3+4i3+4i 比 3+2i3+2i3+2i 大」？

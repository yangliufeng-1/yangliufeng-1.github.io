一个反例就够

所属概念：反例与反证 · 反例 / 反驳

1 反例的法律地位

小学已经会用反例推翻命题。初中要做的事，是把反例的逻辑地位说清楚：

  • 「所有的……都……」这类全称命题：一个反例即否定，不需要更多。
  • 「存在……」这类存在命题：一个正例即证明，同样不需要更多。
否定「所有 x 满足 P(x)」  ⟺  证明「存在 x 不满足 P(x)」\text{否定「所有 } x \text{ 满足 } P(x)\text{」} \iff \text{证明「存在 } x \text{ 不满足 } P(x)\text{」}否定「所有 x 满足 P(x)」⟺证明「存在 x 不满足 P(x)」

这两个方向互为镜像。学会了看这个镜像，就明白反例为什么如此省力：否定一个「所有」，等价于证明一个「存在」——而后者的工作量是一个例子。

2 初中里最经典的反例现场

初中数学有三个地方反例密度极高：

一、分式。「对一切实数成立」的恒等式，最怕分母为零。$\frac{x^2-1}{x-1} = x+1看着永远成立，但 $x=1 时左边无意义。反例不是「算错了」，而是揭示了命题隐含的前提：x≠1x \neq 1x=1。

二、几何命题判断。「有两边及一边对角相等的两个三角形全等」——画两个三角形，摆出 SSA 的组合但不全等，一个图终结命题。几何反例的力量在于图可以直接画出，视觉证据无可辩驳。

三、函数与自变量的范围。「yyy 随 xxx 增大而增大」忘了说「在给定区间上」，反例在区间外候着。

三处的共同点：反例都住在「默认前提」的缝隙里。初中生找反例的主要功课，就是学会把命题隐含的前提挖出来看。

3 与直觉的冲突：反例推翻的是命题，不是「精神」

学生接受反例时有一个顽固的心理障碍：命题被反例推翻后，直觉仍然觉得「它大体上是对的」。

反例：$\frac{x^2-1}{x-1}=x+1在 $x=1 失效。直觉说：「就一个点失效嘛，$x$ 是别的一切值时都成立，算不算基本对？」

数学的回答斩钉截铁：不算。恒等式要么处处成立，要么就是假命题，中间没有「基本对」这个评级。因为数学命题陈述的是精确的逻辑关系，$x=1$ 的那个点不是「小误差」，而是命题为假的判决性证据。

直觉为什么会错？因为它把数学命题当成了经验概括。日常生活里「一般成立、个别例外」的规律照常好用，数学却要求陈述与事实严丝合缝：一个例外就要么收窄命题（加上条件 x\neq 1$），要么推翻。有趣的是，收窄后的命题往往更深刻——正是在给 $\frac{x^2-1}{x-1} 找「失效点」的过程中，数学家发明了「极限」的思想。

4 与后一个学段的螺旋关系

依赖链：小学高年级「举反例说不成立」→ 初中「一个反例就够」→ 初中「反证法」→ 高中「构造出来就证明了」。

小学高  举反例说不成立               反例=一个找出来的特例
   ↓ 反例的逻辑机制被说破
初中    一个反例就够                 ← 本页  否定全称=证明存在
   ↓ 反例背后是「假设矛盾」的思想
初中    反证法的初步接触             反例是反证法的前身
   ↓ 构造成为主动的证明工具
高中    构造出来就证明了             造实例、造反例都是构造

这一级增加的是对反例的元认识：不再只是「会找」，而是知道反例为什么一个就够、它与正例的证据力为何如此不对称。

5 教材里怎么放

人教版初中数学中，反例素材集中在：七年级有理数与代数式（运算律的适用范围）、八年级全等三角形判定（SSA 不能作为判定的反例图形是经典内容）、八年级分式（分母不为零）。教材常以「判断下列命题是否正确，并用反例说明」的题型出现。

编排的用意：把反例放在「命题被广泛误信」的知识点上（SSA、分母为零），让学生在最能感受「一个反例的力量」的地方遇见它，而不是抽象地讲逻辑。

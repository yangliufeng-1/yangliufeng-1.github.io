定积分与不定积分

所属概念：积分 · 黎曼和 / 微积分基本定理

1 高中跳过的那个问题

高中你算 ∫₀¹ x² dx = 1/3，靠的是「找一个原函数，代两个端点」。

但有两个问题被跳过：

  1. 任何函数都能找到原函数吗？ 不能。e^(−x²) 的原函数就写不成初等函数。
  2. 「矩形逼近的极限」一定存在吗？ 不一定。函数振荡得太厉害时，黎曼和没有极限。

大学的第一件事，是把「计算」和「存在性」分开。

2 黎曼可积：什么样的函数能积分

定积分存在（黎曼可积）的判定条件，常见的有两条充分条件：

函数类型 是否可积 说明
闭区间上连续 ✅ 可积 最基本的情形，高中只处理这一类
有有限个第一类间断点 ✅ 可积 分段函数、跳跃点
狄利克雷函数（有理数为 1，无理数为 0） ❌ 不可积 任何分割下上和与下和的差都不趋于 0

判定工具是达布上和与下和：如果上和的极限与下和的极限相等，积分存在。 这不是新公式，是把「矩形逼近」做成可判定的形式。

3 不定积分 ≠ 定积分

这一组概念高中常混着讲，大学必须拆开：

定积分 不定积分
是什么 一个数（有向面积） 一族函数（全体原函数）
符号 ∫ᵃᵇ f(x) dx ∫f(x) dx = F(x) + C
依赖什么 依赖区间 [a,b] 不依赖区间

+C 不是笔误，也不是形式要求——它是「所有原函数构成一个平移族」这一事实的完整表达。 丢掉 C 就等于说「每个函数只有一个原函数」，这是错的。

4 微积分基本定理：两个版本

第一基本定理（变上限积分求导）：

F(x) = ∫ᵃˣ f(t) dt  ⟹  F'(x) = f(x)     （f 连续时）

它说明连续函数一定有原函数——这个结论高中从未提及，但它才是「积分与微分互逆」的严格基础。

第二基本定理（牛顿-莱布尼茨）：

∫ᵃᵇ f(x) dx = F(b) − F(a)

它把「求积分」转化为「求原函数」，这才是高中真正在用的那个。

5 螺旋的最后一环：从「会算」到「知道什么时候算不出来」

∫ 是求面积（小学，规则图形）
   ↓ 曲边怎么办
定积分 = 矩形逼近的极限（高中，直观）        ← integral@high
   ↓ 存在性 + 严格定义
黎曼可积 / 变上限积分 / 基本定理证明（本页）

这里有个值得记住的教训：e^(−x²) 的积分算不出来，但它从 0 到 ∞ 的定积分是 √π/2。 「有答案」和「有初等原函数」是两件完全不同的事。

7 自测

  • ∫ x² dx 和 ∫₀¹ x² dx 分别是什么类型的结果？一个是数还是一族函数？
  • 为什么 ∫₀¹ 1/x dx 发散，而 ∫₁² 1/x dx 收敛？
  • 用第一基本定理说明：d/dx ∫₀ˣ sin(t²) dt 等于什么？这个原函数能用初等函数写出吗？
  • 一个函数有有限个跳跃间断点，它可积吗？说明理由。

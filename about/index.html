关于 Math Atlas

它是什么

一个把「数学概念如何跨学段被重建」画出来的索引站。数据模型是两个实体： Concept（概念身份，如「分数」）与 Unit（某概念在某学段的呈现， 如「分数的初步认识」）。所有前置依赖都指向 Unit，而不是 Concept—— 因为「学有理数」依赖的是「小学学会除法」这个具体单元，不是抽象的「除法」。

它明确不做什么

  • 不托管教材原文。教材只以「版本 · 册次 · 章节」的引用形式出现。
  • 不做视频、不做题库。差异化在「螺旋可见」与「参数化演示」，不在内容体量。
  • 不做账号系统。本图谱不需要用户身份即可浏览。

骨架与血肉

当前 80 个概念、168 个学段单元。其中 168 个有完整长文， 0 个有演示引用，0 个只有标题与教材章节。 这不是缺陷，是刻意的取舍：结构优先于内容， 未完成的部分在界面上是可见的（空心圆 / 「待长」标记），而不是被藏起来。

数据与校验

单一事实源是 data/graph.seed.json，由 scripts/validate_graph.py 在构建前做三道校验：Schema 合法性、图论不变式（无环、双向边一致、id 规范）、 业务不变式（完整长文必须有对应文件）。

三个参考对象，各取了什么

  • polytech-tree：取了「扁平 JSON + 前置关系数组 + 校验脚本」的数据形态， 弃了它的 3D 塔楼视觉（「高度=年代、角度=领域」与「学段×学科」不对应）。
  • ChinaTextbook：仅作为离线抽取章节结构的输入，不进入发布产物。
  • modevol：取了「长文 + 分节 + 嵌入任务块 + 右侧目录」的阅读形态。

本项目只呈现知识结构，不托管任何教材原文。教材仅以「版本 · 册次 · 章节」的引用形式出现。
